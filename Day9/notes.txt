Animations:
-------------------------------
    To animate css elements
    @Keyframe myName{
        from{font-size:20px;}
        To{font-size:40px;}
    }

Animation properties
--------------------------------------------
    animation-name 
    animation-duration 
    animation-timing-function 
    animation-delay
    animation-iteration-count
    animation-direction

    In short cut we can write it as 
        animation:myName 2s linear 3s infinite normal


% in Animation
--------------------------
    @Keyframe myName{
        0%{font-size:20px;}
        50%{font-size:30px;}
        100%{font-size:40px;}
    }


Media Queries:
---------------------------------------
    helps in creating the responsive websites

    @media(width: 600px){
        div{
            background-color: pink;
        }
    }

    @media(min-width: 600px){
        div{
            background-color: skyblue;
        }
    }

    @media(min-width: 200px) and (min-width: 300px)
    {
        div{
            background-color: green;
        }
    }


Position:
-------------------------------------
    static - default Position( the top, right,left,bottom and z-index properties have no effect)
    relative - element is relative to itself(the top, right, bottom,left and z-axis will work)
    absolute - Positioned relative to its closest to Positioned ancestor (removed from the flow)
    fixed - Positioned relative to browser (removed from the flow)
    sticky - Positioned based on the user's scroll Position
