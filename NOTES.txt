tags in html
----------------------
    tags are the predefined words which are enclosed with both the opening and  closing angular tags(<>)
    ex:<h1>, <div>,<a>

    Types of tags:
    ------------------
        1.paired tags
        2.Unpaired tags
    
    1.Paired tags:
    --------------
        Any tags having both opening and closing tags is called as paired tags.

        ex: 1.All heading tags <!--Block level element-->
                    <h1>heading tag-1</h1> <!--h${heading tag-$}*6-->
                    <h2>heading tag-2</h2>
                    <h3>heading tag-3</h3>
                    <h4>heading tag-4</h4>
                    <h5>heading tag-5</h5>
                    <h6>heading tag-6</h6>
            2.Formatting tags
                <b></b>      - font bold
                <strong></strong>    - font bold
                <i></i>        - font italic
                <em></em>      - font italic
                <mark></mark>  - light the content
                <u></u>        - underline
                <sub></sub>    - subscript
                <sup></sup>     - superscript
                <marquee></marquee>   - to scroll the content
                <center></center>   - align content to center(only work for block level elements)
                <strick></strick>    - 
            3.other tags
